The footer below the inspector controls what the graph shows behind the curves. These settings are saved per track and kept when you load a preset.

## Spectrum

**Analyzer** shows the spectrum before the EQ (**Pre**, a line), after it (**Post**, a filled area), both, or neither. Its level scale is on the right of the graph, in dBFS. The pause button freezes the trace so you can study it.

Prism measures the spectrum about 60 times a second, from the two channels mixed to mono. **Pre** is the input after the IN gain; **Post** is the output after the OUT gain, so the gap between them is the EQ curve plus the output gain. A full-scale sine reads 0 dBFS at its frequency (exactly so with the flat top window; up to about 1.8 dB less with the others, between FFT bins). While Prism is bypassed, only **Pre** shows. With the analyzer off and the spectrogram hidden, Prism measures nothing.

The settings button next to it opens:

| Setting   | Choices                                                        |
| --------- | -------------------------------------------------------------- |
| FFT size  | 2k, 4k, 8k or 16k points                                       |
| Window    | Hann, Blackman–Harris, Hamming, Flat top                       |
| Smoothing | Off, 1/12, 1/6 or 1/3 octave                                   |
| Response  | Slow, Medium or Fast: how quickly the trace follows the signal |
| Tilt      | 0, 3, 4.5 or 6 dB per octave                                   |
| Floor     | −60, −90 or −120 dBFS                                          |
| Peak hold | Off or On                                                      |

## Spectrogram

The spectrogram button replaces the spectrum with its recent history: frequency across, as on the graph, and time sweeping down over about four seconds. Brighter means louder, from the analyzer's floor up to 0 dBFS. It shows the output (the input while Prism is bypassed) frame by frame, without the spectrum's smoothing or averaging, so its detail follows the FFT size: 16k points tell notes a few hertz apart; 2k points follow fast changes more closely. The window and tilt apply as they do to the spectrum, and the spectrogram is measured even with the analyzer off.

## Pitch keyboard

The keyboard button adds a piano strip along the frequency axis, with each C labelled, so you can match a band to a note. The keys nearest the selected bands light up.

## Phase

**Display: Phase** switches the gain axis to ±180° and draws the combined phase response of the current filters, with the magnitude curve kept faintly behind it. It shows the filters' math; it is not a measurement.
