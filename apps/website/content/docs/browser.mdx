## Choose a source

- **Synth loop:** Press Play below the plugin.
- **Audio file:** Open the settings next to Play, select **Audio file**, and choose a file your browser can decode. The file stays on your device.

The audio processing is not connected yet, so the demo plays the source unchanged. Everything in the editor works: add and shape bands, try the presets, and switch between A and B.
