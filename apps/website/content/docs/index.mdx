---
title: Getting started
description: A four-band equalizer for VST3 hosts and the browser.
---

Prism has a low shelf, two midrange bells, and a high shelf. All four bands start at 0 dB, so the default settings leave your audio unchanged.

1. [Play the browser demo](/docs/browser) and start the synth loop.
2. Turn a band up or down to hear what it changes. See [Controls](/docs/controls) for the four frequencies.
3. Switch to **Original** to compare with the unprocessed signal, then switch back to **Prism**.

## Install the VST3

Prism runs in DAWs that load VST3 effects on 64-bit Linux and Windows.
